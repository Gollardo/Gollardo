# Alexander Ignatyev

For a long time, most of the software I built stayed private — tools for my own
work, business, experiments, or just things I wanted to exist.

Recently, I started releasing some of them as open source.

The turning point was losing a personal finance application I had relied on for
years after it was acquired and eventually discontinued. I didn't really like
the idea that a useful tool could simply disappear because someone else decided
its time was over.

So I started building Hermes.

Since then, the rule has been pretty simple: if I build something that might be
useful to other people too, I want to at least consider making it public.

## Projects

### Hermes

Self-hosted personal finance software focused on planning ahead rather than
just recording the past.

It started as a replacement for a discontinued application I used myself and
grew into my attempt to build a finance tool that can't simply disappear
because a company changes direction.

→ [Hermes](https://github.com/Gollardo/Hermes)

### Hygieia

A native macOS disk-space explorer for understanding what takes up space and
cleaning it safely.

This one started in a much less dramatic way: I wanted a certain kind of disk
utility, couldn't even get the software I liked to accept my payment, got
annoyed, and eventually decided to build my own.

→ [Hygieia](https://github.com/Gollardo/Hygieia)

## What's with the names?

I seem to have accidentally started a tradition of naming projects after
figures from Greek mythology.

Hermes — trade, exchange and movement of money.

Hygieia — cleanliness and hygiene.

The names usually have something to do with what the software is supposed to do.

No relation to the Kratos avatar. Probably.
